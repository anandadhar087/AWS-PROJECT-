# CloudWatch Monitoring and CPU Spike Detection 

This project demonstrates AWS CloudWatch monitoring and CPU spike detection for AWS infrastructure. It focuses on collecting CPU utilization metrics, monitoring resource performance, and identifying abnormal CPU usage using CloudWatch.

## Project Overview

The main objective of this project is to monitor AWS resources and detect high or abnormal CPU utilization. CloudWatch metrics and alarms are used to continuously observe CPU performance and generate alerts when CPU usage crosses a defined threshold.

## AWS Services Used

* Amazon CloudWatch
* CloudWatch Metrics
* CloudWatch Alarms
* Amazon SNS

## Key Features

* Monitor CPU utilization in real time
* Detect CPU spikes using CloudWatch
* Create CloudWatch alarms for high CPU utilization
* Send notifications when CPU thresholds are exceeded
* Integrate CloudWatch events with AWS Lambda
* Automate responses to monitoring events
